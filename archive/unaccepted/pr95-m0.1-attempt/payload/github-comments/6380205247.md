# Architectural disposition — superseded without merge

Greg has decided that the multi-megabyte M0.1 occurrence inventory and related generated migration metadata must not enter the compiler repository’s production ancestry.

This draft is therefore **rejected as an integration vehicle**, not merged, and superseded by a dedicated public migration-evidence repository: `gregkrsak/bowfin-migration-ledger`.

The useful work in this branch may inform the replacement design, but it will be rebuilt from the accepted staging baseline with:

- a compact, human-reviewable classification source;
- a committed deterministic generator and validator;
- full generated inventories retained outside the compiler repository;
- exact source commit/tree and evidence commit/tree binding;
- no execution, approval, custody, replay, resource, or merge authority; and
- no circular self-reference between a source candidate and its evidence.

Closing this PR does not accept M0.1, authorize M1, modify staging or `prod`, or authorize any external cutover.
